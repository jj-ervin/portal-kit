# Contributing to Portal Kit

Portal Kit has begun fresh implementation of its accepted architecture. No code extraction from GC Portal, Cockpit, or adjacent products has been approved.

## What is welcome now

- issue reports;
- product-boundary feedback;
- interoperability and deployment use cases; and
- design proposals that do not include copied implementation code.

## Pull requests

Do not submit code or documentation pull requests yet. Portal Kit uses `AGPL-3.0-only` for its public community license while preserving the copyright owner's option to offer separate commercial licenses. A contributor agreement or equivalent rights policy must be reviewed and published before outside copyrightable contributions can be accepted.

This temporary restriction avoids accepting work under unclear or incompatible rights. It will be replaced with a normal contribution process after that policy decision.

## Future source files

Unless a file clearly states otherwise, future original Portal Kit source files must carry:

```text
SPDX-License-Identifier: AGPL-3.0-only
```

Do not copy code, schemas, assets, or documentation from GC Portal, Cockpit, Observatory Core, Sealdex, or another project merely because it is locally accessible. Record provenance and verify license compatibility before proposing reuse.
